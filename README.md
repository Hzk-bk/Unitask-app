# UniTask

UniTask is a mobile task management application developed using Kotlin, Jetpack Compose, Firebase Authentication, and Cloud Firestore.

## Features

### Authentication

* User Registration
* User Login
* Auto Login
* Logout
* Error Handling

### Task Management (CRUD)

* Create Tasks
* View Tasks
* Update Tasks
* Delete Tasks

### Extensions

* Input Validation
* Task Status Toggle (Open / Completed)

## Technologies Used

* Kotlin
* Jetpack Compose
* Firebase Authentication
* Cloud Firestore
* GitHub
* Trello

## Project Management

Development was managed using GitHub for version control and Trello for sprint planning and task tracking.
